02

The Idea Behind CTAG-FX

A sound description.
A new control space.

CTAG-FX explores a different approach to text-guided audio effects: constructing the control space of an FX processor rather than adjusting parameters within a predefined FX chain.

  1. 01 / DESCRIBETextual Sound Description
  2. 02 / A&R-CTAGSynthesizer Parameter Configuration
  3. 03 / CTAG-FXRole-Based Synth-to-FX Reinterpretation
  4. 04 / PROCESSTone-Shaping Audio FX

REPRESENTATIVE SYNTH-TO-FX REINTERPRETATIONS

ADSR↓Pre-EQ / Tone Stack

Envelope roles become fixed spectral contours, rather than time-varying envelope generators.

VCO↓Drive / Fuzz

Contrasting source roles become smooth and aggressive nonlinear coloration; no oscillator audio is transferred.

Mod Matrix↓Static Routing

Influence relationships become bounded offsets across drive, EQ and noise controls.

Inside the Tone-Shaping Processor

01 / AUDIO PATHS

The mixer combines a clean path, a processed path, and an independent noise path before the final output stages.

02 / SYNTH-DERIVED CONTROLS

Synthesizer parameter roles become controls for EQ, drive, saturation, mixing, and input/output gain.
External audio supplies the signal; oscillator output is not transferred.

03 / CONTROL ROUTING

The Mod Matrix links four static character axes to five targets through bounded control offsets.
It shapes control relationships, rather than adding time-varying modulation to the audio path.

04

Evaluation

Different roles.
Measurable differences.

KEY FINDING

Role-based mapping produced prompt-specific spectral and nonlinear behavior; scrambling reduced separation.

EXPERIMENTAL SETUP

The processor test bypassed A&R-CTAG: GPT-4o directly instantiated configurations from four tone prompts. Ten configurations per prompt were evaluated on a held-out 10-second guitar recording.

The ablation retained parameter values and permuted their control assignments, using 30 shared permutations.

Real-Time Use via NAM

Once a CTAG-FX configuration is fixed, its input-output response can be captured with Neural Amp Modeler (NAM) and loaded into a compatible host for real-time processing.

Signal-level analysis and embedding similarity are reported here; perceptual correspondence remains to be evaluated. See the preprint.
